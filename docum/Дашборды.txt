🏆 Готовые дашборды для главной страницы (MIT)
1. Soft Dashboard Django (рекомендую для вашего дизайна)
Создан командой Creative-Tim, распространяется под MIT License . Идеально подходит, если вам нравится современный, "мягкий" дизайн.

Установка:

bash
pip install django-admin-soft-dashboard
Настройка:

python
# settings.py
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    # ... стандартные приложения
    'soft_dashboard',  # ← добавляем
    'your_app',
]

# Подключаем статику
STATIC_URL = '/static/'
STATIC_ROOT = BASE_DIR / 'staticfiles'
Создание главной страницы:

python
# your_app/views.py
from django.shortcuts import render
from django.contrib.auth.decorators import login_required

@login_required
def dashboard(request):
    # Добавьте свою бизнес-логику
    context = {
        'total_users': User.objects.count(),
        'total_subscriptions': Sub.objects.filter(is_delete=False).count(),
        'recent_payments': Bill.objects.filter(status='success')[:5],
    }
    return render(request, 'soft_dashboard/index.html', context)

# your_app/urls.py
from django.urls import path
from .views import dashboard

urlpatterns = [
    path('', dashboard, name='dashboard'),
]
Результат: Полноценный дашборд с графиками, таблицами, виджетами, работающий по адресу / .

3. django-admin-tools (гибкая кастомизация)
Позволяет создавать дашборд из модулей (виджетов), которые можно перетаскивать и настраивать через интерфейс .

bash
pip install django-admin-tools
python
# dashboard.py
from admin_tools.dashboard import modules, Dashboard

class CustomDashboard(Dashboard):
    columns = 2
    title = "Мой дашборд"
    
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        
        # Виджет со статистикой подписок
        self.children.append(modules.LinkList(
            title="Быстрые действия",
            children=[
                {'title': 'Новая подписка', 'url': '/admin/sub/sub/add/'},
                {'title': 'Посмотреть платежи', 'url': '/admin/bill/bill/'},
            ]
        ))
        
        # Виджет с последними платежами
        self.children.append(modules.LinkList(
            title="Последние платежи",
            children=[
                {'title': f"{p.amount} ₽ - {p.sub.user}", 'url': f"/admin/bill/bill/{p.id}/"}
                for p in Bill.objects.filter(status='success')[:5]
            ]
        ))

Soft Dashboard  - это тоже набор виджетов?
Прочитано 10 веб-страниц
Soft Dashboard — это набор готовых страниц и компонентов, а не набор отдельных виджетов, которые можно перетаскивать как в Saby . Думайте о нём как о готовом "скелете" интерфейса.

Вместо того чтобы самому верстать боковое меню, шапку и сетку для карточек, вы получаете их уже готовыми. Внутри этого каркаса вы сами размещаете свои виджеты: таблицы с последними платежами, графики, статистику — всё то, что должно быть на главной странице .

📊 Что вы получаете из коробки?
Готовый UI-каркас: Вы сразу получаете рабочий шаблон с адаптивным меню, боковой панелью и всеми основными HTML-страницами .

Библиотека компонентов: В вашем распоряжении более 70 готовых элементов: кнопки, карточки, поля ввода, навбары и многое другое . Вы можете собрать из них свой дашборд, как из кубиков.

Страницы аутентификации: Готовые страницы для входа, регистрации и сброса пароля, которые уже интегрированы с Django .

Темная тема: Поддержка светлой и темной темы, которая сохраняется в браузере .

🛠️ Как это интегрировать в ваш проект
Самый простой способ — это установить готовую библиотеку:

bash
pip install django-admin-soft-dashboard
Затем добавить её в settings.py (важно: до django.contrib.admin) и в urls.py :

python
# settings.py
INSTALLED_APPS = [
    'admin_soft.apps.AdminSoftDashboardConfig', # 👈 Добавить первым
    'django.contrib.admin',
    # ... ваши приложения (users, billing...)
]

# urls.py
urlpatterns = [
    path('', include('admin_soft.urls')), # 👈 Главная страница будет из пакета
    path('admin/', admin.site.urls),
]
✍️ Как адаптировать под свой дизайн
Пакет спроектирован так, чтобы его было легко кастомизировать .

Меняем цвета: В папке вашего приложения (например, dashboard) создайте структуру templates/includes/ и скопируйте туда файл sidebar.html из виртуального окружения. Изменив CSS-классы в этом файле, вы поменяете цвет меню по всему сайту .

Добавляем свои виджеты: Главная страница — это обычный шаблон. Вы можете переопределить его, создав файл templates/pages/index.html в своем приложении. Внутри вы вольны выводить любые данные из ваших моделей (например, список активных подписок или сумму последних платежей) .

💡 Что выбрать?
Soft Dashboard — это готовый интерфейс для главной страницы. Он даёт вам современный каркас, который вы наполняете своей логикой и виджетами.

Если вы хотите не каркас, а набор отдельных блоков, которые можно переставлять мышкой (как в Saby), то вам нужны инструменты вроде django-admin-tools.

В вашем случае, чтобы быстро создать главную страницу для сотрудников, Soft Dashboard — идеальный выбор. Вы получаете профессиональный дизайн, а всё, что вам останется — вывести в его карточки данные из ваших моделей Bill и Sub .

django-tabbed-admin (и его форки) — это библиотека, которая позволяет разбить форму редактирования модели в админке на вкладки (табы). Это особенно полезно, когда у модели много полей или несколько встроенных форм (inlines), которые не помещаются на одной странице.

Однако есть важный нюанс: в вашем requirements.txt указана версия django-tabbed-admin==1.0.2, которая была выпущена в 2018 году и не поддерживает Django 6.0. Она совместима только с Python 2.7 и Django 1.10/1.11.

Чтобы использовать эту функциональность с Django 6.0, нужно установить современный форк. Самый свежий вариант — django4-tabbed-admin или django-tabbed-admin-u, которые адаптированы под новые версии.

Как это выглядит и работает
Вместо одной длинной формы вы получаете интерфейс с вкладками, где можно логически сгруппировать поля и даже разместить inlines в разных вкладках.

Вот пример, как это настраивается (для работы требуется активировать jQuery UI):

python
from django.contrib import admin
from tabbed_admin import TabbedModelAdmin
from .models import Band, Musician, Album

class MusicianInline(admin.StackedInline):
    model = Musician
    extra = 1

class AlbumInline(admin.TabularInline):
    model = Album
    extra = 1

@admin.register(Band)
class BandAdmin(TabbedModelAdmin):
    model = Band

    # Группируем поля и inlines для первой вкладки
    tab_overview = (
        (None, {
            'fields': ('name', 'bio', 'style')   # поля
        }),
        MusicianInline,                         # inline форма
        ('Contact', {                           # ещё одна группа полей
            'fields': ('agent', 'phone', 'email')
        })
    )

    # Вторая вкладка только с inlines
    tab_album = (
        AlbumInline,
    )

    # Создаём сами вкладки с названиями
    tabs = [
        ('Основная информация', tab_overview),
        ('Альбомы', tab_album)
    ]

1. django-mptt (древесные структуры)
Позволяет создавать иерархические структуры в админке (категории, меню, комментарии). В админке появляется красивое дерево с отступами и возможностью перетаскивания.

# models.py
from mptt.models import MPTTModel, TreeForeignKey

class Category(MPTTModel):
    name = models.CharField(max_length=50)

    class MPTTMeta:
        order_insertion_by = ['name']

# admin.py
from mptt.admin import MPTTModelAdmin

4. qrcode (генерация QR-кодов)
Хотя это не админка напрямую, можно легко добавить генерацию QR-кодов в админке для отображения ссылок, токенов или платёжных данных.

python
# admin.py
from django.utils.html import format_html
import qrcode
from io import BytesIO
import base64

def qr_code_preview(self, obj):
    qr = qrcode.make(obj.token)
    buffer = BytesIO()
    qr.save(buffer, format='PNG')
    img_str = base64.b64encode(buffer.getvalue()).decode()
    return format_html('<img src="data:image/png;base64,{}" width="100" />', img_str)

🏆 Лучший выбор: django-allauth
Это самое популярное и мощное решение на рынке. Оно закрывает практически все ваши требования и активно поддерживается.

Что дает: Полный набор для аутентификации: регистрация, вход, выход, смена и сброс пароля, подтверждение email, управление учетной записью. Поддерживает как обычный вход по email/username, так и вход через соцсети (Google, GitHub, Telegram и другие) .

Защита и безопасность: Имеет встроенную защиту от перебора паролей (rate limiting), предотвращает определение существования учетной записи (account enumeration prevention) . Все формы имеют CSRF-защиту.

Подтверждение email: Отправка писем для верификации email-адреса встроена "из коробки". Нужно только настроить SMTP .

Telegram: Поддержка входа через Telegram реализована как один из провайдеров (Open ID Connect) .

Лицензия: MIT .

Статистика: Более 9.4k звезд на GitHub, сотни контрибьюторов, постоянно обновляется (последний релиз — март 2026) .

Поддержка Django: Работает с последними версиями Django, включая 6.0.

Отличный вопрос! django-allauth идеально вписывается в любой дизайн, потому что он намеренно не имеет собственных стилей и предоставляет гибкую систему кастомизации .

Как это работает
django-allauth поставляется с "пустыми" шаблонами без CSS-классов. Вся стилизация ложится на вас, что позволяет идеально интегрировать формы в ваш существующий дизайн (цветовую гамму, шрифты, расположение) .

1. Самый быстрый: готовые темы Bootstrap (рекомендуется, если у вас Bootstrap)

INSTALLED_APPS = [

Конечно, можно и, более того, это лучший способ создать мощный и профессиональный дашборд. Готовые дашборды (такие как Soft Dashboard) дают вам красивую оболочку, а django-tables2 и django-filter наполняют её интерактивными, адаптивными таблицами. Они работают вместе идеально.

🚀 Как это работает вместе
Мощь django-tables2 в том, что он не привязан к какой-то одной теме. Вы просто говорите ему: «Используй шаблоны Bootstrap 5», и он автоматически подхватывает стили вашего дашборда . Это значит, что таблицы с пагинацией, сортировкой и фильтрацией будут выглядеть так, будто они всегда были частью вашего Soft Dashboard.

class BillTable(tables.Table):

# dashboard/filters.py
import django_filters
from .models import Bill

class BillFilter(django_filters.FilterSet):
    class Meta:
        model = Bill
        fields = {
            'status': ['exact'],       # Фильтр по точному совпадению статуса
            'amount': ['gt', 'lt'],    # Фильтр по сумме (больше, меньше)

Шаг 4. Создаем представление (View)
Теперь объединим всё в представлении. Класс SingleTableView из django-tables2 упрощает эту задачу .

python
# dashboard/views.py
from django_tables2 import SingleTableView
from django_filters.views import FilterView
from .models import Bill
from .tables import BillTable
from .filters import BillFilter

class BillListView(SingleTableView, FilterView):
    model = Bill
    table_class = BillTable
    template_name = 'dashboard/bill_list.html'
    filterset_class = BillFilter

    def get_queryset(self):
        # Применяем фильтр к основному запросу
        queryset = super().get_queryset()
        self.filterset = self.filterset_class(self.request.GET, queryset=queryset)
        return self.filterset.qs

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        # Передаём фильтр в шаблон, чтобы отобразить форму
        context['filter'] = self.filterset
        return context

А фиксация строк, столбцов?
Прочитано 10 веб-страниц
Что касается фиксации (закрепления) строк и столбцов в django-tables2 — возможности разные.

📌 Фиксация строк (Pinned Rows)
Эта функция в django-tables2 есть и работает отлично. Она позволяет закрепить определенные строки (например, строку с итогами) вверху или внизу таблицы .

Главные особенности:

Не зависит от сортировки и пагинации: закрепленные строки всегда будут видны на любой странице таблицы .

Реализация: нужно переопределить в классе таблицы методы get_top_pinned_data() или get_bottom_pinned_data(), которые возвращают итератор (список, QuerySet) с данными для закрепленных строк .

Пример из документации :

python
class Table(tables.Table):
    first_name = tables.Column()
    last_name = tables.Column()

    def get_top_pinned_data(self):
        return [
            {"first_name": "Janet", "last_name": "Crossen"},
            {"first_name": "Trine", "last_name": None}  # для None будет показано значение по умолчанию
        ]
По умолчанию, <tr> закрепленных строк получают CSS-класс pinned-row .

📌 Фиксация столбцов (Pinned / Frozen Columns)
Это возможность закрепить один или несколько столбцов слева или справа от таблицы, чтобы они оставались на месте при горизонтальной прокрутке.

В django-tables2 эта функция отсутствует. В библиотеке нет встроенной опции, аналогичной pinned: "left" .

Это означает, что вам придется реализовать фиксацию столбцов самостоятельно, используя CSS и, возможно, JavaScript.

🛠️ Как реализовать фиксацию столбцов самостоятельно
Есть несколько способов, которые отлично работают в паре с django-tables2:

CSS с position: sticky (самый простой способ)
Этот метод использует чистый CSS и не требует JavaScript .

Принцип: для ячеек закрепляемого столбца (<th>, <td>) задается position: sticky; left: 0;.

Пример настройки в django-tables2:

python
class BillTable(tables.Table):
    # ... ваши колонки ...
    id = tables.Column(attrs={"td": {"style": "position: sticky; left: 0; background-color: white;"}, "th": {"style": "position: sticky; left: 0; background-color: #f9fafb;"}})
    name = tables.Column(attrs={"td": {"style": "position: sticky; left: 60px; background-color: white;"}, "th": {"style": "position: sticky; left: 60px; background-color: #f9fafb;"}})
    # ... остальные колонки

    class Meta:
        model = Bill
        fields = ('id', 'name', 'amount', 'status')
        attrs = {"class": "table table-striped", "style": "width: 100%; overflow-x: auto; display: block;"}
В этом примере left: 0; фиксирует колонку id, а left: 60px; — следующую колонку name. Важно задать display: block; overflow-x: auto; для <table> или его обертки, чтобы появилась горизонтальная прокрутка . Также нужно продумать background-color, чтобы ячейки не "просвечивали" при прокрутке.

Использование специализированных JavaScript-библиотек (AG Grid, TanStack Table)
Это более мощный путь, который я рекомендовал ранее. Эти библиотеки имеют встроенную поддержку фиксации столбцов (свойство pinned: "left" или fixed: "left"), inline-редактирования, группировки и многого другого.

Они предназначены для создания полноценных интерактивных таблиц и идеально вписываются в вашу концепцию дашборда, работая поверх django-tables2 или вместо него.

💡 Что выбрать?
Если вам нужна только фиксация шапки таблицы (заголовка), а не столбцов, то CSS-решение с position: sticky для <thead> работает отлично и легко настраивается .

Простой, но трудоемкий — реализовать это самому на CSS.

🏆 AG Grid Community Edition — абсолютный лидер
Это самое мощное и популярное решение. AG Grid — это индустриальный стандарт для таблиц в веб-приложениях. Важно: Community версия имеет лицензию MIT и абсолютно бесплатна для коммерческого использования .

Что даёт Community версия (MIT):

✅ Фиксация столбцов (pinned: 'left' или 'right') — то, что вам нужно .

✅ Inline-редактирование ячеек .

✅ Группировка строк (Row Grouping), сортировка, фильтрация.

✅ Пагинация, выбор строк, экспорт в CSV.

✅ 4 встроенные темы (Alpine, Balham, Material, Quartz) для стилизации под ваш дашборд .

✅ Поддержка React, Vue, Angular и чистого JavaScript (Vanilla JS), что делает его интеграцию с любым проектом очень гибкой .

Что не входит в Community и остаётся в платной Enterprise версии:

❌ Excel-экспорт.

❌ Сводные таблицы (Pivoting).

❌ Расширенная группировка и агрегация данных.

❌ Интегрированные графики (Integrated Charting) .

Как это работает с Django:
Вы отдаёте данные из вашего Django-приложения через API (например, через Django REST Framework), а на фронтенде рендерите таблицу AG Grid. Это наиболее профессиональный и масштабируемый подход.

✨ RevoGrid — специализированное решение
Если ваша главная задача — работа с очень большими объёмами данных (миллионы ячеек), RevoGrid — отличная альтернатива. Она также распространяется под MIT лицензией .

Ключевые особенности:

✅ Фиксация строк и столбцов (Pinned rows and columns) .

✅ Группировка столбцов (Nested headers).

✅ Inline-редактирование.

✅ Виртуализация для молниеносной работы с огромными наборами данных.

✅ Поддержка Vue, React, Angular, Svelte, а также использование как веб-компонента .

В чём разница с AG Grid:
RevoGrid изначально проектировалась как "excel-like" компонент для работы с большими данными. Она имеет немного другой API и может быть предпочтительнее, если вам не нужны все "корпоративные" функции AG Grid.

🧩 TanStack Table — для максимальной гибкости (но требует больше кода)
Если вы ищете не "коробочное" решение, а инструмент для создания собственной кастомной таблицы, то TanStack Table (ранее React Table) — это лучший выбор. Это библиотека-голд стандарт с открытым исходным кодом .

Ключевые особенности:

✅ MIT лицензия.

✅ Поддержка фиксации столбцов на уровне API (columnPinning) .

✅ Максимальная гибкость — вы сами решаете, как рендерить ячейки, заголовки и элементы управления.

✅ Невероятно мощный API для управления состоянием, сортировкой, фильтрацией и группировкой .

✅ Поддержка React, Vue, Solid, Svelte, Qwik .

В чём сложность:
В отличие от AG Grid или RevoGrid, TanStack Table не предоставляет готовые UI-компоненты (такие как полосы прокрутки, элементы пагинации). Она даёт вам "движок" таблицы и логику, а верстать внешний вид и обрабатывать события (например, редактирование ячейки) вам придётся самостоятельно . Это идеальный вариант, если вы хотите полностью контролировать каждый пиксель вашей таблицы.

🚀 Ключевые компоненты вашей системы
1. Универсальный слой для мессенджеров: Django Unicom
Это идеальная основа для вашей задачи. Django Unicom предоставляет унифицированный API для Telegram, WhatsApp, Email и WebChat .

Единая лента сообщений: Вся переписка из разных каналов хранится в моделях Chat и Message .

Приём и отправка: Работает через вебхуки (Telegram) или IMAP/SMTP (Email). Вы пишете channel.send_message(), а Unicom сам решает, как отправить это в нужный мессенджер .

Вложения и кнопки: Поддерживает отправку файлов и интерактивные кнопки для Telegram и WebChat .

2. CRM и группировка контактов: Django CRM
Django CRM предоставляет готовую структуру для управления контактами и группировки. Это приложение работает прямо из коробки и содержит всё необходимое .

Иерархия: Модели "Компании" (группы) и "Контактные лица" (контрагенты) позволяют реализовать несколько уровней группировки .

Связь с сообщениями: CRM хранит историю email-переписки и может быть расширена для связи с моделями Message из Unicom .

Рассылки: Встроенный модуль Mailing CRM позволяет создавать кампании и динамические шаблоны для email-рассылок .

3. Фоновая обработка и очереди: django-background-tasks
Отправка сообщений, особенно с вложениями и через внешние API, не должна блокировать работу интерфейса. Для этого нужна асинхронная очередь .

Работа без Redis: django-background-tasks хранит задачи прямо в базе данных, что идеально для старта и средних нагрузок .

Простота: Вы просто оборачиваете функцию отправки в декоратор @background(), и она выполнится в фоне .

Повторные попытки: Библиотека автоматически повторяет отправку в случае временных ошибок (проблемы с сетью, лимиты API) .

Вам нужно будет добавить ForeignKey в модель Message из Unicom, чтобы связать её с контактами в CRM. Это можно сделать через наследование или сигналы.

python
# billing/signals.py
from django.dispatch import receiver
from unicom.models import Message
from django_crm.models import Contact

@receiver(Message.message_received)
def link_message_to_contact(sender, message, **kwargs):
    # Пытаемся найти контакт по email или telegram_id
    contact, created = Contact.objects.get_or_create(
        email=message.sender_email,
        defaults={'name': message.sender_name}
    )
    message.contact = contact
    message.save()
Шаг 5. Создайте фоновую задачу для отправки
python
# billing/tasks.py
from background_task import background
from unicom.models import Channel
from django_crm.models import Contact

@background(schedule=0)
def send_outgoing_message(contact_id, channel_id, text, file_paths=None):
    contact = Contact.objects.get(id=contact_id)
    channel = Channel.objects.get(id=channel_id)

    # Логика выбора чата по контакту и каналу
    chat_id = contact.get_chat_id_for_channel(channel)
    message_data = {'chat_id': chat_id, 'text': text}

    if file_paths:
        # В Unicom можно передать список файлов
        message_data['file_paths'] = file_paths

    channel.send_message(message_data)
    # Логируем отправку в историю
    contact.add_history(f"Sent via {channel.name}: {text[:50]}")
Шаг 6. Реализуйте группировку и рассылки
Используйте встроенные возможности CRM для группировки контактов. Для рассылки вы просто создаёте фоновую задачу для каждого контакта в группе .

python
# billing/marketing.py
from .tasks import send_outgoing_message

def send_newsletter_to_group(group_id, channel_id, subject, html_body):
    contacts = Contact.objects.filter(group_id=group_id, is_active=True)
    for contact in contacts:
        send_outgoing_message(contact.id, channel_id, subject, html_body)

Единая структура данных: Вместо того чтобы хранить сообщения из Telegram в одной таблице, а из Email — в другой, вы получаете единые модели Chat и Message .

CRM из коробки: Модели для компаний, контактов, сделок и задач уже готовы и работают в админке .

🧠 Почему стандартный Django не подходит
Django изначально проектировался для статичных схем: модели пишутся в коде, миграции создаются и применяются. Runtime-создание моделей не поддерживается из коробки.

Однако с помощью динамического создания классов (type) можно создавать модели на лету, а схему БД — через обычные SQL-запросы (без миграций).

🏗️ Архитектура системы: "Модель для создания моделей"
Вам нужна метамодель — структура, которая хранит описание пользовательских сущностей, а затем генерирует из них настоящие Django-модели.

1. Модели для хранения метаданных
python
# billing/dynamic/models.py
from django.db import models

class Entity(models.Model):
    """Пользовательская сущность (аналог таблицы)"""
    name = models.CharField(max_length=100, unique=True)
    description = models.TextField(blank=True)
    created_by = models.ForeignKey('users.User', on_delete=models.CASCADE)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.name

class Field(models.Model):
    """Поле пользовательской сущности"""
    DATA_TYPES = [
        ('char', 'Строка'),
        ('text', 'Текст'),
        ('int', 'Целое число'),
        ('float', 'Дробное число'),
        ('bool', 'Да/Нет'),
        ('date', 'Дата'),
        ('datetime', 'Дата и время'),
        ('fk', 'Связь с другой сущностью'),
    ]

    entity = models.ForeignKey(Entity, on_delete=models.CASCADE, related_name='fields')
    name = models.CharField(max_length=100)  # имя поля в модели
    verbose_name = models.CharField(max_length=100)  # отображаемое имя

    target_entity = models.ForeignKey('self', null=True, blank=True, on_delete=models.SET_NULL)  # для fk
    sort_order = models.IntegerField(default=0)

        unique_together = [['entity', 'name']]

2. Сервис для генерации моделей
Используем type() для динамического создания классов:

python
# billing/dynamic/model_builder.py
from django.db import models
from django.contrib.contenttypes.models import ContentType
from .models import Entity, Field

class ModelBuilder:
    """Построитель динамических моделей"""

    def __init__(self, entity: Entity):
        self.entity = entity
        self._model = None

    def build(self):
        """Создаёт Django-модель на основе метаданных"""
        attrs = self._build_fields()
        attrs['__module__'] = 'billing.dynamic.models'  # обязательный атрибут
        attrs['Meta'] = self._build_meta()

        # Динамическое создание класса модели
        model_class = type(
            self.entity.name,           # имя класса
            (models.Model,),            # базовые классы
            attrs                       # атрибуты
        )

        self._model = model_class
        return model_class

    def _build_fields(self):
        """Создаёт поля модели"""
        fields = {}
        for field in self.entity.fields.all():
            field_kwargs = self._get_field_kwargs(field)
            fields[field.name] = self._get_field_class(field)(**field_kwargs)

        # Добавляем стандартные поля
        fields['created_at'] = models.DateTimeField(auto_now_add=True)
        fields['updated_at'] = models.DateTimeField(auto_now=True)
        fields['created_by'] = models.ForeignKey('users.User', on_delete=models.SET_NULL, null=True)

        return fields

    def _get_field_class(self, field: Field):
        """Возвращает класс поля Django по типу"""
        mapping = {
            'char': models.CharField,
            'text': models.TextField,
            'int': models.IntegerField,
            'float': models.FloatField,
            'bool': models.BooleanField,
            'date': models.DateField,
            'datetime': models.DateTimeField,
            'fk': models.ForeignKey,
        }
        return mapping.get(field.data_type, models.CharField)

    def _get_field_kwargs(self, field: Field):
        """Параметры для создания поля"""
        kwargs = {
            'verbose_name': field.verbose_name,
            'null': not field.is_required,
            'blank': not field.is_required,
        }

        if field.max_length and field.data_type == 'char':
            kwargs['max_length'] = field.max_length

        if field.data_type == 'fk' and field.target_entity:
            kwargs['to'] = field.target_entity.name  # имя целевой модели

        return kwargs

    def _build_meta(self):
        """Создаёт внутренний класс Meta"""
        class Meta:
            db_table = f"dynamic_{self.entity.name.lower()}"
            verbose_name = self.entity.name
            verbose_name_plural = f"{self.entity.name}ы"

        return Meta

from django.contrib.contenttypes.models import ContentType
from .model_builder import ModelBuilder

class DynamicModelRegistry:
    """Реестр динамических моделей"""
    _models = {}

    @classmethod
    def get_model(cls, entity_id):
        """Получить или создать динамическую модель"""
        if entity_id not in cls._models:
            from .models import Entity
            entity = Entity.objects.get(id=entity_id)
            builder = ModelBuilder(entity)
            model = builder.build()

            # Регистрируем в ContentType
            ct, _ = ContentType.objects.get_or_create(
                app_label='dynamic',
                model=entity.name.lower()
            )
            cls._models[entity_id] = model

        return cls._models[entity_id]

from django.http import JsonResponse
from django.db.models import Count, Sum, Avg
from billing.dynamic.registry import DynamicModelRegistry

def report_data(request, report_id):
    report = Report.objects.get(id=report_id)
    Model = DynamicModelRegistry.get_model(report.source_entity.id)

    queryset = Model.objects.all()

    # Применяем фильтры
    if report.filters:
        queryset = queryset.filter(**report.filters)

    # Группировка и агрегация
    if report.grouping:
        values = queryset.values(*report.grouping)
        aggregations = {}

        for field in report.fields:
            if field.get('aggregation') == 'count':
                aggregations[f"{field['name']}_count"] = Count(field['name'])
            elif field.get('aggregation') == 'sum':
                aggregations[f"{field['name']}_sum"] = Sum(field['name'])
            elif field.get('aggregation') == 'avg':
                aggregations[f"{field['name']}_avg"] = Avg(field['name'])

        if aggregations:
            queryset = values.annotate(**aggregations)

    data = list(queryset)
    return JsonResponse({'data': data, 'chart_config': report.chart_config})

⚠️ Критические предостережения
Проблема	Решение
Безопасность	Никогда не позволяйте пользователям выполнять произвольный SQL. Все операции — через Django ORM.
Производительность	Кэшируйте созданные модели (DynamicModelRegistry).
Резервное копирование	Динамические таблицы нужно бэкапить отдельно.
Миграции	Не используйте стандартные миграции. Управляйте схемой через SQL-запросы.
Индексы	Создавайте их вручную при добавлении полей.
📌 Итог: что вы получите
Пользователь создаёт сущность — через интерфейс вводит название, добавляет поля, выбирает типы, указывает связи.

Система создаёт таблицу — генерирует Django-модель, создаёт SQL-таблицу и индексы.

Пользователь строит отчёты — выбирает сущность, поля, группировку, тип графика.

Отчёт отображается — через ECharts с возможностью экспорта в Excel/PDF.

Вся эта система работает без перезагрузки сервера. Это сложно, но реализуемо. Готов помочь с реализацией любого блока.

import axios from 'axios';
import FieldSelector from './FieldSelector';
import FilterBuilder from './FilterBuilder';
import DataPreview from './DataPreview';
import ChartPreview from './ChartPreview';

const ReportBuilder = () => {
    const [entities, setEntities] = useState([]);
    const [selectedEntity, setSelectedEntity] = useState(null);
    const [fields, setFields] = useState([]);
    const [filters, setFilters] = useState([]);
    const [grouping, setGrouping] = useState([]);
    const [chartType, setChartType] = useState('table');
    const [previewData, setPreviewData] = useState(null);
    const [loading, setLoading] = useState(false);
    const [reportId, setReportId] = useState(null);

    // Загрузка списка сущностей
    useEffect(() => {
        axios.get('/api/entities/').then(res => setEntities(res.data));
    }, []);

    // Обновление данных при изменении настроек
    useEffect(() => {
        if (selectedEntity) {
            refreshPreview();
        }
    }, [selectedEntity, fields, filters, grouping, chartType]);

    const refreshPreview = async () => {
        setLoading(true);
        try {
            const response = await axios.post('/api/reports/preview/', {
                source: { entity_id: selectedEntity.id },
                fields,
                filters,
                grouping,
                chart_type: chartType,
            });
            setPreviewData(response.data);
        } catch (error) {
            console.error('Ошибка загрузки данных:', error);
        } finally {
            setLoading(false);
        }
    };

    const saveReport = async () => {
        const response = await axios.post('/api/reports/', {
            name: 'Новый отчёт',
            source: { entity_id: selectedEntity.id },
            fields,
            filters,
            grouping,
            chart_type: chartType,
        });
        setReportId(response.data.id);
        alert('Отчёт сохранён');
    };

    return (
        <div className="report-builder">
            <div className="sidebar">
                <h3>Выбор данных</h3>
                <select onChange={e => setSelectedEntity(entities.find(e => e.id == e.target.value))}>
                    <option value="">Выберите сущность</option>
                    {entities.map(e => <option key={e.id} value={e.id}>{e.name}</option>)}
                </select>

                {selectedEntity && (
                    <>
                        <FieldSelector
                            entityId={selectedEntity.id}
                            fields={fields}
                            onChange={setFields}
                        />
                        <FilterBuilder
                            entityId={selectedEntity.id}
                            filters={filters}
                            onChange={setFilters}
                        />
                        <div className="grouping">
                            <h4>Группировка</h4>
                            <select multiple onChange={e => setGrouping([...e.target.selectedOptions].map(o => o.value))}>
                                {fields.map(f => (

                                ))}
                            </select>
                        </div>
                        <div className="chart-type">
                            <h4>Тип визуализации</h4>
                            <select value={chartType} onChange={e => setChartType(e.target.value)}>
                                <option value="table">Таблица</option>
                                <option value="bar">Столбчатая диаграмма</option>
                                <option value="line">Линейный график</option>
                                <option value="pie">Круговая диаграмма</option>
                                <option value="area">Областная диаграмма</option>
                            </select>
                        </div>

                        <button onClick={saveReport} className="btn-save">Сохранить отчёт</button>
                    </>
                )}
            </div>

            <div className="preview">
                <div className="toolbar">
                    <button onClick={refreshPreview} disabled={loading}>Обновить</button>
                    {reportId && (
                        <>
                            <button onClick={() => window.open(`/api/reports/${reportId}/export/excel/`)}>📊 Excel</button>
                            <button onClick={() => window.open(`/api/reports/${reportId}/export/pdf/`)}>📄 PDF</button>
                        </>
                    )}
                </div>

                {loading && <div className="loader">Загрузка...</div>}

                {previewData && !loading && (
                    chartType === 'table'
                        ? <DataPreview data={previewData} />
                        : <ChartPreview type={chartType} data={previewData} config={previewData.chart_config} />
                )}
            </div>
        </div>
    );
};

        return () => chart?.dispose();

# billing/reports/api.py
from rest_framework.decorators import api_view
from rest_framework.response import Response
from django.db import connection
from billing.dynamic.registry import DynamicModelRegistry

@api_view(['POST'])
def preview_report(request):
    """Возвращает данные для предпросмотра отчёта"""
    config = request.data

    # Получаем динамическую модель
    entity_id = config['source']['entity_id']
    Model = DynamicModelRegistry.get_model(entity_id)

    # Строим запрос
    queryset = Model.objects.all()

    # Применяем фильтры
    for f in config.get('filters', []):
        lookup = f"{f['field']}__{f.get('op', 'exact')}"
        queryset = queryset.filter(**{lookup: f['value']})

    # Группировка и агрегация
    if config.get('grouping'):
        values = queryset.values(*config['grouping'])
        annotations = {}
        for field in config['fields']:
            if field.get('aggregation'):
                annotations[f"{field['name']}_{field['aggregation']}"] = {
                    'sum': models.Sum(field['name']),
                    'avg': models.Avg(field['name']),
                    'count': models.Count(field['name']),
                }[field['aggregation']]
        if annotations:
            queryset = values.annotate(**annotations)

    # Сбор данных для фронтенда
    rows = list(queryset)
    columns = [
        {'field': f['name'], 'verbose': f.get('verbose', f['name'])}
        for f in config['fields']
    ]

    # Подготовка для графика
    categories = []
    series_data = {}
    for row in rows:
        if config.get('grouping'):
            cat = '-'.join(str(row.get(g)) for g in config['grouping'])
            categories.append(cat)
            for field in config['fields']:
                if field.get('aggregation'):
                    series_data.setdefault(field['verbose'], []).append(row.get(f"{field['name']}_{field['aggregation']}", 0))

    return Response({
        'columns': columns,
        'rows': rows,
        'categories': categories,
        'series': [{'name': k, 'data': v} for k, v in series_data.items()],
        'chart_config': config.get('chart_config', {}),
    })

import xlwt
from io import BytesIO
from django.http import HttpResponse
from reportlab.lib import colors
from reportlab.lib.pagesizes import A4, landscape
from reportlab.platypus import SimpleDocTemplate, Table, TableStyle, Paragraph
from reportlab.lib.styles import getSampleStyleSheet
from urllib.parse import quote
import json

def export_excel(report_id):
    from .models import Report
    from billing.dynamic.registry import DynamicModelRegistry

    report = Report.objects.get(id=report_id)
    Model = DynamicModelRegistry.get_model(report.source['entity_id'])

    # Получаем данные
    queryset = Model.objects.all()
    for f in report.filters:
        queryset = queryset.filter(**{f['field']: f['value']})

    # Создаём Excel
    wb = xlwt.Workbook(encoding='utf-8')
    sheet = wb.add_sheet('Отчёт')
    sheet.col(0).width = 5000

    # Стили
    header_style = xlwt.easyxf('font: bold on; pattern: pattern solid, fore_colour light_blue; align: horiz center')
    data_style = xlwt.easyxf('align: horiz left')

    # Заголовки
    for col, field in enumerate(report.fields):
        sheet.write(0, col, field.get('verbose', field['name']), header_style)

    # Данные
    for row, obj in enumerate(queryset, 1):
        for col, field in enumerate(report.fields):
            value = getattr(obj, field['name'], '')
            if field.get('data_type') == 'bool':
                value = 'Да' if value else 'Нет'
            sheet.write(row, col, str(value), data_style)

    response = HttpResponse(content_type='application/vnd.ms-excel')
    response['Content-Disposition'] = f'attachment; filename*=utf-8\'\'{quote(report.name)}.xls'
    wb.save(response)
    return response

def export_pdf(report_id):
    from .models import Report
    from billing.dynamic.registry import DynamicModelRegistry

    report = Report.objects.get(id=report_id)
    Model = DynamicModelRegistry.get_model(report.source['entity_id'])

    # Получаем данные
    queryset = Model.objects.all()

    # Подготовка данных для PDF
    headers = [field.get('verbose', field['name']) for field in report.fields]
    data = []
    for obj in queryset[:1000]:  # ограничим для производительности
        row = []
        for field in report.fields:
            value = getattr(obj, field['name'], '')
            if field.get('data_type') == 'bool':
                value = 'Да' if value else 'Нет'
            row.append(str(value))
        data.append(row)

    # Создаём PDF
    buffer = BytesIO()
    doc = SimpleDocTemplate(buffer, pagesize=landscape(A4))
    elements = []

    # Заголовок
    styles = getSampleStyleSheet()
    title = Paragraph(f"<b>{report.name}</b>", styles['Title'])
    elements.append(title)

    # Таблица
    table = Table([headers] + data)
    table.setStyle(TableStyle([
        ('BACKGROUND', (0, 0), (-1, 0), colors.lightblue),
        ('TEXTCOLOR', (0, 0), (-1, 0), colors.black),
        ('ALIGN', (0, 0), (-1, -1), 'CENTER'),
        ('FONTNAME', (0, 0), (-1, 0), 'Helvetica-Bold'),
        ('BOTTOMPADDING', (0, 0), (-1, 0), 12),
        ('BACKGROUND', (0, 1), (-1, -1), colors.beige),
        ('GRID', (0, 0), (-1, -1), 1, colors.black),
    ]))

    elements.append(table)
    doc.build(elements)

    response = HttpResponse(buffer.getvalue(), content_type='application/pdf')
    response['Content-Disposition'] = f'inline; filename*=utf-8\'\'{quote(report.name)}.pdf'
    return response

✅ Лицензии: всё в порядке
Вы можете не беспокоиться о лицензионной чистоте — все перечисленные инструменты имеют разрешительные лицензии.

AG Grid Community — MIT . Полностью свободная лицензия, позволяющая использовать, модифицировать и встраивать библиотеку в любой проект без ограничений. Идеально подходит для коммерческой разработки.

ECharts — MIT . Аналогично, это одна из самых популярных и свободных библиотек для визуализации данных.

Django Unicom — лицензия явно не указана в предоставленных результатах, но, как правило, такие проекты имеют открытую лицензию (например, MIT или BSD). Для точности стоит проверить файл LICENSE в его репозитории.

Django CRM — MIT . Полностью свободен для коммерческого использования.

django-background-tasks — BSD-3-Clause . Это тоже очень свободная лицензия, аналогичная MIT. Однако, есть важный нюанс: проект находится в состоянии "Inactive" (неактивен), последний релиз был более года назад, а последний коммит — больше года . Для долгосрочного проекта я бы рекомендовал рассмотреть более активные альтернативы, такие как Celery или django-q2.

django-tables2 — BSD . Свободная лицензия.

django-filter — BSD-3-Clause . Свободная лицензия.

django-allauth — MIT . Очень популярное и активно поддерживаемое решение для аутентификации.

django-debug-toolbar — BSD . Свободная лицензия.

django-mptt — MIT . Свободная лицензия.

📊 Что позволяет ECharts
ECharts — это не просто библиотека для графиков, а мощный инструмент визуализации данных. Он под капотом использует Canvas, что обеспечивает отличную производительность даже на больших данных.

В контексте вашего конструктора отчетов он позволяет реализовать:

Интерактивность: пользователь может наводить на элементы графиков, кликать по легенде, чтобы скрыть или показать ряды данных, и масштабировать области.

Разнообразие визуализаций: поддерживаются десятки типов диаграмм (столбчатые, линейные, круговые, точечные, тепловые карты, географические карты и многие другие), что идеально подходит для гибкой системы отчетов.

Адаптивность: графики автоматически подстраиваются под размер контейнера, в который они встроены.

Кастомизация: вы можете детально настроить внешний вид под корпоративный стиль (цвета, шрифты, легенды), что соответствует вашему требованию по дизайну.

⚠️ Единственное предостережение по лицензиям
Django CRM (github.com/MicroPyramid/Django-CRM) имеет лицензию MIT, но в выдаче также встречается упоминание пакета "django-crm" с лицензией AGPL-3.0 . Это два разных проекта с похожими названиями.

Чтобы не запутаться, всегда используйте пакет от MicroPyramid. Его репозиторий github.com/MicroPyramid/Django-CRM имеет лицензию MIT и 2k звезд . Это ваш правильный выбор.

Это совсем другой уровень сложности, но он реализуем.

from django.db import models
from django.contrib.auth import get_user_model

User = get_user_model()

class Report(models.Model):
    """Отчёт с WYSIWYG-конфигурацией"""
    name = models.CharField(max_length=200, verbose_name='Название')
    description = models.TextField(blank=True, verbose_name='Описание')
    owner = models.ForeignKey(User, on_delete=models.CASCADE, related_name='reports')
    is_public = models.BooleanField(default=False)

    # Схема отчёта (JSON) — вся структура, позиции, настройки
    config = models.JSONField(default=dict, verbose_name='Конфигурация отчёта')

    # Данные отчёта (кэш, опционально)
    data = models.JSONField(default=dict, blank=True, verbose_name='Кэшированные данные')

    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        verbose_name = 'Отчёт'
        verbose_name_plural = 'Отчёты'

    def __str__(self):
        return self.name

    let grid = null;
    let currentReportId = null;

    // Инициализация GridStack
    function initGrid() {
        grid = GridStack.init({
            cellHeight: 100,
            verticalMargin: 10,
            minRow: 2,
            acceptWidgets: true,
            removable: '.trash',
            resizable: { handles: 'e, se, s, sw, w' }
        });
    }

    // Добавление блока-таблицы
    function addTableBlock(fieldConfig = null) {
        const id = `table_${Date.now()}`;
        const widget = document.createElement('div');
        widget.className = 'grid-stack-item';
        widget.setAttribute('gs-id', id);
        widget.setAttribute('gs-x', 0);
        widget.setAttribute('gs-y', grid.getRow() + 1);
        widget.setAttribute('gs-w', 6);
        widget.setAttribute('gs-h', 4);
        widget.innerHTML = `
            <div class="grid-stack-item-content">
                <div class="block-header">
                    <span class="block-title">Таблица: ${fieldConfig?.title || 'Новая таблица'}</span>
                    <button class="block-settings">⚙️</button>
                    <button class="block-delete">🗑️</button>
                </div>
                <div class="block-content" id="${id}_content" style="height: calc(100% - 30px);"></div>
            </div>
        `;

        grid.addWidget(widget);
        renderTable(id, fieldConfig);
        attachBlockEvents(widget);
    }

    // Рендер таблицы через AG Grid
    async function renderTable(containerId, config) {
        const contentDiv = document.getElementById(`${containerId}_content`);
        if (!contentDiv) return;

        // Получаем данные из API
        const response = await fetch('/api/reports/data/', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(config?.source || { entity: 'bill', fields: ['id', 'amount', 'status'] })
        });
        const data = await response.json();

        // Инициализируем AG Grid
        contentDiv.innerHTML = `<div id="${containerId}_grid" style="height: 100%; width: 100%;"></div>`;
        const gridDiv = document.getElementById(`${containerId}_grid`);

        new agGrid.Grid(gridDiv, {
            columnDefs: data.columns.map(col => ({ field: col.field, headerName: col.verbose, editable: true })),
            rowData: data.rows,
            pagination: true,
            paginationPageSize: 25,
            onCellValueChanged: (event) => {
                // Отправляем изменения в Django
                fetch(`/api/data/${event.data.id}/`, {
                    method: 'PATCH',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ [event.colDef.field]: event.newValue })
                });
            }
        });
    }

    // Добавление блока-графика
    function addChartBlock(config = null) {
        const id = `chart_${Date.now()}`;
        const widget = document.createElement('div');
        widget.className = 'grid-stack-item';
        widget.setAttribute('gs-id', id);
        widget.setAttribute('gs-x', 6);
        widget.setAttribute('gs-y', 0);
        widget.setAttribute('gs-w', 6);
        widget.setAttribute('gs-h', 4);
        widget.innerHTML = `
            <div class="grid-stack-item-content">
                <div class="block-header">
                    <span class="block-title">График: ${config?.title || 'Новый график'}</span>
                    <button class="block-settings">⚙️</button>
                    <button class="block-delete">🗑️</button>
                </div>
                <div class="block-content" id="${id}_content" style="height: calc(100% - 30px);"></div>
            </div>
        `;

        grid.addWidget(widget);
        renderChart(id, config);
        attachBlockEvents(widget);
    }

    // Рендер графика через ECharts
    async function renderChart(containerId, config) {
        const contentDiv = document.getElementById(`${containerId}_content`);
        if (!contentDiv) return;

        // Получаем данные
        const response = await fetch('/api/reports/chart-data/', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(config?.source || { entity: 'bill', field_x: 'created_at', field_y: 'amount' })
        });
        const data = await response.json();

        contentDiv.innerHTML = `<div id="${containerId}_chart" style="height: 100%; width: 100%;"></div>`;
        const chartDiv = document.getElementById(`${containerId}_chart`);

        const chart = echarts.init(chartDiv);
        chart.setOption({
            title: { text: config?.title || 'Аналитика платежей' },
            tooltip: { trigger: 'axis' },
            xAxis: { type: 'category', data: data.categories },
            yAxis: { type: 'value' },
            series: [{ type: 'bar', data: data.values }]
        });
    }

    // Обработка событий блоков (удаление, настройки)
    function attachBlockEvents(widget) {
        widget.querySelector('.block-delete').addEventListener('click', () => grid.removeWidget(widget));
        widget.querySelector('.block-settings').addEventListener('click', () => openBlockSettings(widget));
    }

    // Окно настроек блока (WYSIWYG-редактирование)
    function openBlockSettings(widget) {
        const blockId = widget.getAttribute('gs-id');
        const blockType = widget.querySelector('.block-title').innerText.startsWith('Таблица') ? 'table' : 'chart';

        const modal = document.createElement('div');
        modal.className = 'modal';
        modal.innerHTML = `
            <div class="modal-content">
                <h3>Настройки блока</h3>
                <label>Заголовок: <input type="text" id="block-title" value="${widget.querySelector('.block-title').innerText.replace('Таблица: ', '').replace('График: ', '')}"></label>
                <label>Источник данных:
                    <select id="block-entity">
                        <option value="bill">Платежи</option>
                        <option value="sub">Подписки</option>
                        <option value="user">Пользователи</option>
                    </select>
                </label>
                <label>Поля (через запятую): <input type="text" id="block-fields" value="id,amount,status"></label>
                <button id="save-settings">Сохранить</button>
            </div>
        `;

        document.body.appendChild(modal);

        document.getElementById('save-settings').addEventListener('click', () => {
            const newTitle = document.getElementById('block-title').value;
            const newEntity = document.getElementById('block-entity').value;
            const newFields = document.getElementById('block-fields').value.split(',').map(f => f.trim());

            widget.querySelector('.block-title').innerText = `${blockType === 'table' ? 'Таблица' : 'График'}: ${newTitle}`;

            // Обновляем блок с новыми настройками
            if (blockType === 'table') {
                renderTable(blockId, { source: { entity: newEntity, fields: newFields } });
            } else {
                renderChart(blockId, { source: { entity: newEntity, field_x: 'created_at', field_y: 'amount' } });
            }

            modal.remove();
        });
    }

    // Сохранение отчёта
    async function saveReport() {
        const blocks = [];
        const widgets = grid.getGridItems();

        for (const widget of widgets) {
            const id = widget.getAttribute('gs-id');
            const blockType = widget.querySelector('.block-title').innerText.startsWith('Таблица') ? 'table' : 'chart';
            const title = widget.querySelector('.block-title').innerText.replace('Таблица: ', '').replace('График: ', '');

            blocks.push({
                id: id,
                type: blockType,
                title: title,
                position: {
                    x: parseInt(widget.getAttribute('gs-x')),
                    y: parseInt(widget.getAttribute('gs-y')),
                    w: parseInt(widget.getAttribute('gs-w')),
                    h: parseInt(widget.getAttribute('gs-h'))
                }
            });
        }

        const config = {
            layout: 'grid',
            columns: 12,
            blocks: blocks
        };

        await fetch(`/api/reports/${currentReportId}/`, {
            method: 'PATCH',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ config: config })
        });

        alert('Отчёт сохранён');
    }

        const report = await response.json();
        currentReportId = reportId;

        // Очищаем сетку
        grid.removeAllWidgets();

        // Восстанавливаем блоки
        for (const block of report.config.blocks) {
            if (block.type === 'table') {
                addTableBlock(block);
            } else {
                addChartBlock(block);
            }
        }

Это полноценный WYSIWYG-конструктор отчётов, где пользователь:

Видит отчёт в визуальном редакторе

Меняет расположение блоков (drag & drop)

Настраивает каждый блок (заголовок, источник данных, поля)

Всё это работает без перезагрузки страницы, с использованием современных библиотек под MIT-лицензиями.

Ещё ты мне предлагал ранее Dashboard. Дак вот я хочу, чтобы она никогда не пролистывалась вниз. Она должна состять из блоков nav - всегда фиксирована вверху, footer - всешда фиксирован внизу, left side-bar, right-side-bar - всегда фиксированы слева и справа и у них внутренняя прокрутка независима от всей страницы (т.к. страница никогда не прокручивается). В главной части страницы набор виджетов, коттрые каждый между собой независимы, можно двигать их границы, внутри них свои прокрутки, можно их добавлять динамически (виджеты), расставлять. Такое можно реализовать?
Да, это абсолютно реализуемо. Вы описываете архитектуру, которая в веб-разработке называется "фиксированный макет с независимыми прокрутками" (fixed layout with independent scroll areas). Это классическая компоновка современных десктопных приложений, перенесённая в веб.

Ключевые характеристики:

Страница никогда не прокручивается (body имеет overflow: hidden)

Каждый блок (навбар, сайдбары, футер, виджеты) имеет свою независимую прокрутку

Виджеты можно перетаскивать, менять размеры, добавлять/удалять динамически

Границы виджетов можно двигать (resize)

        let grid = null;
        
        // Функция для создания случайного ID
        function generateId() {
            return 'widget_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
        }
        
        // Создание виджета по типу
        function createWidget(type, id = null, title = null, x = 0, y = 0, w = 4, h = 3) {
            const widgetId = id || generateId();
            const widgetTitle = title || getWidgetTitle(type);
            
            // Создаём элемент виджета
            const widget = document.createElement('div');
            widget.className = 'grid-stack-item';
            widget.setAttribute('gs-id', widgetId);
            widget.setAttribute('gs-x', x);
            widget.setAttribute('gs-y', y);
            widget.setAttribute('gs-w', w);
            widget.setAttribute('gs-h', h);
            
            widget.innerHTML = `
                <div class="grid-stack-item-content">
                    <div class="widget-header">
                        <span class="widget-title">${widgetTitle}</span>
                        <div class="widget-actions">
                            <button class="widget-refresh" title="Обновить">🔄</button>
                            <button class="widget-remove" title="Удалить">✖</button>
                        </div>
                    </div>
                    <div class="widget-body" id="${widgetId}_body">
                        <div style="height: 100%;" id="${widgetId}_content">Загрузка...</div>
                    </div>
                </div>
            `;
            
            grid.addWidget(widget);
            
            // Заполняем содержимое
            renderWidgetContent(widgetId, type);
            
            // Обработчики кнопок
            const removeBtn = widget.querySelector('.widget-remove');
            removeBtn.addEventListener('click', () => grid.removeWidget(widget));
            
            const refreshBtn = widget.querySelector('.widget-refresh');
            refreshBtn.addEventListener('click', () => renderWidgetContent(widgetId, type));
            
            return widgetId;
        }

        function initDragAndDrop() {
            const widgetsList = document.querySelectorAll('.widget-item');
            
            widgetsList.forEach(widget => {
                widget.addEventListener('dragstart', (e) => {
                    e.dataTransfer.setData('text/plain', widget.getAttribute('data-type'));
                    e.dataTransfer.effectAllowed = 'copy';
                });

            gridContainer.addEventListener('dragover', (e) => {
                e.preventDefault();
                e.dataTransfer.dropEffect = 'copy';

                e.preventDefault();
                const type = e.dataTransfer.getData('text/plain');
                if (type) {
                    // Находим координаты в сетке
                    const rect = gridContainer.getBoundingClientRect();
                    const x = Math.floor((e.clientX - rect.left) / 200); // примерная ширина колонки
                    const y = grid.getRow() + 1;
                    createWidget(type, null, null, Math.max(0, x), y, 4, 3);
                }
            });
        }

Что такое GridStack
GridStack.js — это библиотека для создания интерактивных сеток (dashboard), где виджеты можно:

Перетаскивать (drag & drop)

Менять размер (resize)

Добавлять/удалять динамически

Сетка адаптируется под количество колонок

Это фундамент, на котором строятся современные дашборды. Именно GridStack позволяет реализовать ту гибкость, которую вы хотите: независимые виджеты, которые пользователь сам расставляет.

GridStack не даёт готового дизайна — он даёт механику. Дизайн вы делаете сами (или берёте готовые стили).

# dashboard/models.py
from django.db import models
from django.contrib.auth import get_user_model

User = get_user_model()

class DashboardPage(models.Model):
    """Страница дашборда (пользователь может создавать несколько страниц)"""
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='dashboard_pages')
    name = models.CharField(max_length=100, verbose_name='Название страницы')
    slug = models.SlugField(max_length=100, verbose_name='URL')
    parent = models.ForeignKey('self', on_delete=models.CASCADE, null=True, blank=True, related_name='children')
    order = models.IntegerField(default=0, verbose_name='Порядок')
    is_default = models.BooleanField(default=False, verbose_name='Главная страница')
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        unique_together = ['user', 'slug']
        ordering = ['parent__id', 'order', 'name']
        verbose_name = 'Страница дашборда'
        verbose_name_plural = 'Страницы дашборда'

    def __str__(self):
        return f"{self.user.username} / {self.name}"

class DashboardWidget(models.Model):
    """Виджет на странице дашборда"""
    WIDGET_TYPES = [
        ('text', 'Текстовый блок'),
        ('table', 'Таблица'),
        ('chart', 'График'),
        ('stats', 'Статистика'),
        ('calendar', 'Календарь'),
        ('iframe', 'Внешняя страница'),
        ('custom', 'Пользовательский'),
    ]

    page = models.ForeignKey(DashboardPage, on_delete=models.CASCADE, related_name='widgets')
    widget_type = models.CharField(max_length=20, choices=WIDGET_TYPES, default='text')
    title = models.CharField(max_length=200, blank=True, verbose_name='Заголовок')
    content = models.JSONField(default=dict, verbose_name='Содержимое')
    position_x = models.IntegerField(default=0, verbose_name='X позиция (колонка)')
    position_y = models.IntegerField(default=0, verbose_name='Y позиция (ряд)')
    width = models.IntegerField(default=4, verbose_name='Ширина (колонки)')
    height = models.IntegerField(default=3, verbose_name='Высота (ячейки)')
    order = models.IntegerField(default=0, verbose_name='Порядок')
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ['page', 'order', 'position_y', 'position_x']
        verbose_name = 'Виджет'
        verbose_name_plural = 'Виджеты'

    def __str__(self):
        return f"{self.page.name} / {self.get_widget_type_display()} - {self.title or 'без названия'}"

# dashboard/api.py
from rest_framework import viewsets, serializers, permissions
from rest_framework.decorators import action
from rest_framework.response import Response
from .models import DashboardPage, DashboardWidget

class DashboardPageSerializer(serializers.ModelSerializer):
    class Meta:
        model = DashboardPage
        fields = ['id', 'name', 'slug', 'parent', 'order', 'is_default']

class DashboardWidgetSerializer(serializers.ModelSerializer):
    class Meta:
        model = DashboardWidget
        fields = ['id', 'widget_type', 'title', 'content', 'position_x', 'position_y', 'width', 'height', 'order']

class DashboardPageViewSet(viewsets.ModelViewSet):
    serializer_class = DashboardPageSerializer
    permission_classes = [permissions.IsAuthenticated]

    def get_queryset(self):
        return DashboardPage.objects.filter(user=self.request.user)

    @action(detail=True, methods=['get', 'post'])
    def widgets(self, request, pk=None):
        page = self.get_object()
        if request.method == 'GET':
            widgets = page.widgets.all()
            serializer = DashboardWidgetSerializer(widgets, many=True)
            return Response(serializer.data)
        elif request.method == 'POST':
            serializer = DashboardWidgetSerializer(data=request.data)
            if serializer.is_valid():
                serializer.save(page=page)
                return Response(serializer.data)
            return Response(serializer.errors, status=400)

    @action(detail=False, methods=['post'])
    def reorder(self, request):
        """Обновление всех виджетов страницы (позиции, размеры)"""
        page_id = request.data.get('page_id')
        widgets_data = request.data.get('widgets', [])
        page = DashboardPage.objects.get(id=page_id, user=request.user)

        for w_data in widgets_data:
            widget = DashboardWidget.objects.get(id=w_data['id'], page=page)
            widget.position_x = w_data.get('x', widget.position_x)
            widget.position_y = w_data.get('y', widget.position_y)
            widget.width = w_data.get('w', widget.width)
            widget.height = w_data.get('h', widget.height)
            widget.save()

        return Response({'status': 'ok'})

    // Получение CSRF токена
    function getCookie(name) {
        let cookieValue = null;
        if (document.cookie && document.cookie !== '') {
            const cookies = document.cookie.split(';');
            for (let i = 0; i < cookies.length; i++) {
                const cookie = cookies[i].trim();
                if (cookie.substring(0, name.length + 1) === (name + '=')) {
                    cookieValue = decodeURIComponent(cookie.substring(name.length + 1));
                    break;
                }
            }
        }
        return cookieValue;
    }

    // Загрузка страниц
    async function loadPages() {
        const res = await fetch('/api/pages/');
        const pages = await res.json();
        const container = document.getElementById('page-tree');
        container.innerHTML = buildTree(pages, null);
        if (pages.length > 0 && !currentPageId) {
            const defaultPage = pages.find(p => p.is_default) || pages[0];
            await loadPage(defaultPage.id);
        }
    }

    function buildTree(pages, parentId) {
        const children = pages.filter(p => p.parent === parentId);
        if (children.length === 0) return '';
        let html = '<ul class="page-tree">';
        children.forEach(p => {
            html += `
                <li data-id="${p.id}" class="${currentPageId === p.id ? 'active' : ''}">
                    <span>${escapeHtml(p.name)}</span>
                    <span class="page-actions">
                        <button onclick="editPage(${p.id})">✏️</button>
                        <button onclick="deletePage(${p.id})">🗑️</button>
                    </span>
                </li>
            `;
            html += buildTree(pages, p.id);
        });
        html += '</ul>';
        return html;
    }

    function escapeHtml(str) {
        if (!str) return '';
        return str.replace(/[&<>]/g, function(m) {
            if (m === '&') return '&amp;';
            if (m === '<') return '&lt;';
            if (m === '>') return '&gt;';
            return m;
        });
    }

# dashboard/models.py
from django.db import models
from django.contrib.auth import get_user_model

User = get_user_model()

class DashboardPage(models.Model):
    """
    Страница дашборда — может быть корневой страницей сайта,
    разделом или подразделом (любая вложенность)
    """
    user = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name='dashboard_pages',
        verbose_name='Владелец'
    )
    parent = models.ForeignKey(
        'self',
        on_delete=models.CASCADE,
        null=True,
        blank=True,
        related_name='children',
        verbose_name='Родительская страница'
    )
    title = models.CharField(
        max_length=200,
        verbose_name='Название страницы'
    )
    slug = models.SlugField(
        max_length=200,
        verbose_name='URL (уникальный в пределах сайта)'
    )
    site_id = models.IntegerField(
        default=0,
        verbose_name='ID сайта (для группировки страниц в сайты)'
    )
    site_name = models.CharField(
        max_length=100,
        blank=True,
        verbose_name='Название сайта'
    )
    icon = models.CharField(
        max_length=50,
        blank=True,
        verbose_name='Иконка (Font Awesome класс)'
    )
    is_default = models.BooleanField(
        default=False,
        verbose_name='Стартовая страница сайта'
    )
    is_visible = models.BooleanField(
        default=True,
        verbose_name='Отображать в меню'
    )
    order = models.IntegerField(
        default=0,
        verbose_name='Порядок сортировки'
    )
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        verbose_name = 'Страница дашборда'
        verbose_name_plural = 'Страницы дашборда'
        ordering = ['site_id', 'parent__id', 'order', 'title']
        unique_together = [['user', 'site_id', 'slug']]
        indexes = [
            models.Index(fields=['user', 'site_id']),
            models.Index(fields=['user', 'parent']),
        ]

    def __str__(self):
        prefix = f"[{self.site_name}] " if self.site_name else ""
        return f"{prefix}{self.title}"

    def get_full_path(self):
        """Возвращает полный путь к странице (для навигации)"""
        if self.parent:
            return f"{self.parent.get_full_path()}/{self.slug}"
        return f"/{self.slug}"

    def get_site_pages(self):
        """Возвращает все страницы текущего сайта"""
        return DashboardPage.objects.filter(
            user=self.user,
            site_id=self.site_id
        ).select_related('parent')

    def get_tree(self):
        """Возвращает дерево страниц текущего сайта"""
        pages = self.get_site_pages()
        return self._build_tree(pages, None)

    @staticmethod
    def _build_tree(pages, parent_id):
        tree = []
        for page in pages.filter(parent_id=parent_id):
            tree.append({
                'id': page.id,
                'title': page.title,
                'slug': page.slug,
                'icon': page.icon,
                'is_default': page.is_default,
                'order': page.order,
                'children': DashboardPage._build_tree(pages, page.id)
            })
        return sorted(tree, key=lambda x: (x['order'], x['title']))


class DashboardWidget(models.Model):
    """Виджет на странице дашборда"""

    def get_children(self, obj):

    def get_full_path(self, obj):
        return obj.get_full_path()


class DashboardPageViewSet(viewsets.ModelViewSet):
    serializer_class = DashboardPageSerializer
    permission_classes = [permissions.IsAuthenticated]

    def get_queryset(self):
        return DashboardPage.objects.filter(user=self.request.user)

    @action(detail=False, methods=['get'])
    def sites(self, request):
        """Возвращает список сайтов пользователя с группировкой страниц"""
        pages = DashboardPage.objects.filter(user=request.user)
        sites = pages.values('site_id', 'site_name').distinct().order_by('site_id')
        result = []
        for site in sites:
            site_pages = pages.filter(site_id=site['site_id'])
            result.append({
                'site_id': site['site_id'],
                'site_name': site['site_name'] or f'Сайт #{site["site_id"]}',
                'pages': DashboardPageSerializer(site_pages.filter(parent=None), many=True).data
            })
        return Response(result)

    @action(detail=False, methods=['post'])
    def create_site(self, request):
        """Создаёт новый сайт (группу страниц)"""
        site_id = DashboardPage.objects.filter(user=request.user).aggregate(
            max_id=models.Max('site_id')
        )['max_id'] or 0
        site_id += 1
        return Response({'site_id': site_id})

    @action(detail=False, methods=['post'])
    def move_page(self, request):
        """Перемещает страницу в новую позицию (сортировка, смена родителя)"""
        page_id = request.data.get('page_id')
        new_parent_id = request.data.get('new_parent_id')
        new_order = request.data.get('new_order', 0)

        page = DashboardPage.objects.get(id=page_id, user=request.user)
        if new_parent_id:
            page.parent_id = new_parent_id
        page.order = new_order
        page.save()

        # Перенумеровываем остальные страницы того же родителя
        siblings = DashboardPage.objects.filter(
            user=request.user,
            parent_id=page.parent_id
        ).exclude(id=page_id).order_by('order')
        for i, sibling in enumerate(siblings):
            sibling.order = i
            sibling.save()

        return Response({'status': 'ok'})

    function getCookie(name) {
        let cookieValue = null;
        if (document.cookie && document.cookie !== '') {
            const cookies = document.cookie.split(';');
            for (let i = 0; i < cookies.length; i++) {
                const cookie = cookies[i].trim();
                if (cookie.substring(0, name.length + 1) === (name + '=')) {
                    cookieValue = decodeURIComponent(cookie.substring(name.length + 1));
                    break;
                }
            }
        }
        return cookieValue;
    }

# models.py
from django.db import models
from django.contrib.auth import get_user_model

User = get_user_model()

class UserSubscription(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    trial_start = models.DateTimeField(auto_now_add=True)
    trial_end = models.DateTimeField(null=True, blank=True)
    plan = models.CharField(max_length=20, default='trial')  # trial, pro, business
    is_active = models.BooleanField(default=True)

    def is_trial_valid(self):
        if not self.trial_end:
            # 30 дней от регистрации
            self.trial_end = self.trial_start + timedelta(days=30)
            self.save()
        return timezone.now() < self.trial_end and self.plan == 'trial'


# middleware.py
class TrialMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        if request.user.is_authenticated:
            subscription = UserSubscription.objects.get(user=request.user)
            if subscription.plan == 'trial' and not subscription.is_trial_valid():
                # Пробный период закончился
                request.trial_expired = True
                return redirect('subscription_required')
        return self.get_response(request)

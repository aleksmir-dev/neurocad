# Политика обработки персональных данных

**Дата последнего обновления:** {date}

## 1. Общие положения

Настоящая Политика определяет порядок обработки персональных
данных посетителей сайта.

## 2. Какие данные обрабатываются

Сайт может обрабатывать следующие данные посетителей:

- IP-адрес;
- данные cookie-файлов;
- сведения о браузере и устройстве.

## 3. Цели обработки

Данные обрабатываются для обеспечения работы сайта, сбора
обезличенной статистики и улучшения качества обслуживания.

## 4. Права посетителя

Посетитель вправе запросить информацию об обработке своих
данных, а также потребовать их уточнения или удаления, направив
запрос владельцу сайта.

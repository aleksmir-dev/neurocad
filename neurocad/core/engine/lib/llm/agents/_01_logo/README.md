# _01_logo

**Агент:** Logo

## Что делает
Генерирует один SVG-логотип (иконку-символ) на основе текстового описания.

## Входные данные
- `provider` — объект LLM-провайдера для генерации.
- `user_message` — текстовое описание того, что нужно нарисовать.
- `alt` — необязательная подсказка (alt-текст) для контекста.

# neurocad 0.1.26

Release date: 2026-09-27

---

## English

### Added

- **Demo pages, importable into an existing DB.** Ten pre-built pages ship with the package and can be imported into a live `neurocad.db` without wiping it:
  - «Космологическая сингулярность» — статья о начале и пределах описания.
  - «Детский сад „Солнышко“» — забота, развитие и радость каждый день.
  - «Спа-салон для отдыха» — восстановление и забота о себе.
  - «Родовое поместье» — земля для жизни вашей семьи.
  - «Приключения Электроника» — фанатская страница легендарного фильма.
  - «Юлия Кузнецова» — авторский блог.
  - «Картины художников Урала» — выставка живописи уральских мастеров.
  - «Гостья из будущего» — советский научно-фантастический телесериал.
  - «Музыкальная студия полного цикла» — запись, сведение и мастеринг.
  - «Точка стрижки» — парикмахерская, где вас стригут по-настоящему.

  The dump uses `INSERT` only (no `DELETE FROM pages`), omits `pages.id` so SQLite assigns it automatically, and pins every row to `nav_id = 1`.

### Fixed

- No code changes; this release is data-only.

## Русский

### Добавлено

- **Демо-страницы с импортом в существующую базу.** Десять готовых страниц едут с пакетом и импортируются в живую `neurocad.db` без её очистки:
  - «Космологическая сингулярность» — статья о начале и пределах описания.
  - «Детский сад „Солнышко“» — забота, развитие и радость каждый день.
  - «Спа-салон для отдыха» — восстановление и забота о себе.
  - «Родовое поместье» — земля для жизни вашей семьи.
  - «Приключения Электроника» — фанатская страница легендарного фильма.
  - «Юлия Кузнецова» — авторский блог.
  - «Картины художников Урала» — выставка живописи уральских мастеров.
  - «Гостья из будущего» — советский научно-фантастический телесериал.

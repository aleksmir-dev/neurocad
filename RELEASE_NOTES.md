# neurocad 1.0.28

Release date: 2026-10-15

---

## English

- **Mobile viewport fix.** `03_layout.css` and `chat.css` now use `100dvh` (with a `100vh` fallback) instead of `100vh`, so the chat input stays above the browser and system bars in portrait mode. This replaces the previous behaviour where the input field was hidden behind the system navigation bar.

## Русский

- **Исправление мобильного вьюпорта.** `03_layout.css` и `chat.css` теперь используют `100dvh` (с фолбэком `100vh`) вместо `100vh`, поэтому поле ввода чата остаётся над браузерными и системными панелями в портретной ориентации. Это заменяет прежнее поведение, когда поле ввода было скрыто за системной панелью навигации.

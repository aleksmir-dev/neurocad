# neurocad 0.1.21

Release date: 2026-09-27

---

## English

### Added

- **Effects palette** — a full library of ready-made `fx-*` effects for the GrapesJS editor, backed by `editor/effects/registry.json` and served through `GET /editor/effects`. Clicking an effect applies (or removes) the class on the selected element.
- **LLM-generated effects** — the "create effect" flow asks the model for a draft, previews it live in the editor, and saves it to the registry on confirmation.
- **Images palette** — a new "Изображения" category in the block panel, backed by `editor/images/registry.json`. Clicking an image inserts it into the canvas as an `<img>` block.
- **Auto-collected illustrations** — every SVG generated by the LLM on step 4 of the create flow is saved to the images registry, so illustrations accumulate in the palette across runs.
- **One-off SVG importer** — `test/import_svgs_from_db.py` extracts large inline SVGs from existing pages in `neurocad.db` and adds them to the images registry (icons, duplicates, and unsafe SVGs are skipped).
- **Page-level CSS builder** — `word/css_builder.py` assembles the full CSS of a page at save time and freezes it in `Page.css`. The public page loads only `public.css` + `pages/<id>.css`.

### Changed

- **Frozen page CSS** — updating an effect or a block in a future version of the constructor cannot change an already-published page. The page's CSS is fixed at save time.
- **Editor sub-APIs unified** — effects and images are mounted under the same `editor` router.
- **Planner prompt** — layout blocks (grids, containers, flex-shell) are excluded from the LLM catalog, so the model composes pages from ready-made sections and elements only.

### Removed

- `effects/manifest.js` — the API is now the single source of truth for the effects list.
- Static import of `blocks/manifest.js` in `word.js` — replaced with a dynamic, versioned import.

### Fixed

- Empty `<p></p>` placeholder on freshly opened pages is now removed right after the initial data load and after rollback.
- `DataLoader` — `child.removed` is called as a method, not used as a boolean (which silently skipped every component).
- Generated SVG save path in `step.py` is now correct — every illustration reaches the images registry.

## Русский

### Добавлено

- **Библиотека эффектов** — полный набор готовых `fx-*` эффектов для редактора GrapesJS, источник — `editor/effects/registry.json`, API — `GET /editor/effects`. Клик по эффекту навешивает (или снимает) класс на выделенный элемент.
- **Генерация эффектов через LLM** — запрос «создай эффект» получает от модели черновик, показывает его в редакторе вживую и сохраняет в реестр после подтверждения.
- **Библиотека изображений** — новая категория «Изображения» в панели блоков, источник — `editor/images/registry.json`. Клик по изображению вставляет его в canvas как блок `<img>`.
- **Автосбор иллюстраций** — каждый SVG, сгенерированный LLM на шаге 4, сохраняется в реестр изображений, поэтому иллюстрации накапливаются в палитре между запусками.
- **Одноразовый импорт SVG** — `test/import_svgs_from_db.py` вытаскивает крупные инлайн-SVG из существующих страниц в `neurocad.db` и добавляет их в реестр изображений (иконки, дубликаты и небезопасные SVG пропускаются).
- **Сборщик CSS страницы** — `word/css_builder.py` собирает полный CSS страницы при сохранении и замораживает его в `Page.css`. Публичная страница грузит только `public.css` + `pages/<id>.css`.

### Изменено

- **CSS страницы замораживается** — обновление эффекта или блока в новой версии конструктора не меняет уже опубликованную страницу. CSS страницы фиксируется при сохранении.
- **Под-API редактора объединены** — эффекты и изображения смонтированы под одним роутером `editor`.
- **Промпт планировщика** — блоки категории «Разметка» (сетки, контейнеры, flex-shell) исключены из каталога для LLM. Модель собирает страницу только из готовых секций и элементов.

### Удалено

- `effects/manifest.js` — единственный источник правды теперь API.
- Статический импорт `blocks/manifest.js` в `word.js` — заменён динамическим импортом с версией.

### Исправлено

- Пустой `<p></p>` на только что открытой странице теперь удаляется сразу после первичной загрузки данных и после отката.
- `DataLoader` — `child.removed` вызывается как метод, а не используется как булево (иначе проверка молча пропускала все компоненты).
- Путь сохранения сгенерированных SVG в `step.py` теперь корректный — каждая иллюстрация попадает в реестр изображений.

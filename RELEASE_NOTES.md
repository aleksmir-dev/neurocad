# neurocad 1.0.18

Release date: 2026-10-08

---

## English

Articles can now be grouped into folders. Create a folder with the "Создать папку" button, open it by clicking, and go back up with the "Вернуться" card — both in the admin panel and in the public catalog at `/pages`. Nesting depth is unlimited: folders can contain other folders, breadcrumbs in the public catalog show the full path, and each folder gets its own SEO-friendly URL (`/pages/<id>`). Articles created inside a folder are saved in it automatically.

## Русский

Статьи теперь можно группировать по папкам. Папка создаётся кнопкой «Создать папку», открывается кликом, а вернуться на уровень выше можно карточкой «Вернуться» — и в админке, и в публичном каталоге на `/pages`. Глубина вложенности не ограничена: папки могут содержать другие папки, хлебные крошки в публичном каталоге показывают весь путь, и у каждой папки свой SEO-дружественный URL (`/pages/<id>`). Статьи, созданные внутри папки, сохраняются в ней автоматически.
